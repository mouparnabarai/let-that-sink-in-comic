# Let That Sink In — Interactive A3 Comic Book

An interactive 17-page A3 vertical comic book web application designed for desktop browsers and iPadOS (standalone Home Screen Web App / PWA).

## Features
- **Exact A3 Portrait Format** (`1 : 1.4142`) scaled cleanly to any screen or iPad viewport.
- **Manual Analog Page-Turn Effect** — peel corners or outer page edges to flip forward and backward with realistic paper curl shading, low-GSM show-through, cast shadows, and paper rustle audio.
- **Per-Panel Video Controls** — `1.5cm` play buttons with exclusive playback (starting one video stops any other playing video, and turning a page stops active playback).
- **Custom Interactive Panels** — manual horizontal swipe panel on Page 4, multi-stage scroll-up & pinch/tap zoom sequence with reset on Page 9, sequential 5-part full-page player on Page 10, and layered looping background + toggleable slide-up GIF on Page 15.
